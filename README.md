# Orgo Organic Shop - static website

Pages: index.html (Home), about.html, products.html, blog.html, contact.html
Shared header and footer are included in every page.

Open index.html in any browser - no build step or server is needed.

- css/style.css   all styles (responsive)
- js/main.js      mobile menu, cart counter, product filter/search, animated counters, form validation
- images/         original SVG artwork drawn for this project

Notes
- The contact and newsletter forms only validate in the browser. Connect them to a backend or a form service to send messages.
- The cart is a demo counter stored in localStorage.
- Brand name "Orgo", address, phone and email are placeholders - search and replace them in the HTML files.
